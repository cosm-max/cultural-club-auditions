Cultural Club Auditions Page: Jain University
A single-page website for the Jain University cultural club auditions (Design Club, Pixel Poetry, Fashion Team on 25-26 September). Built with plain HTML, CSS and JavaScript in one file, with no frameworks, so it deploys anywhere.

Components: a full-screen hero with a cursor-following spotlight that reveals a second colourful layer (CSS radial-gradient mask, eased with requestAnimationFrame, and an automatic drift on touch screens); a live countdown that switches between "starts in", "on right now" and "over"; audition cards with a details modal built on the native <dialog> element; a "My list" feature saved in localStorage; a two-day schedule; and a footer linking to the club's Instagram.

Design choices: dark plum theme with one rose accent, Playfair Display italic paired with Inter, and a motion-site inspired hero. The audition data lives in one array at the top of the script, so the content is easy to edit.
